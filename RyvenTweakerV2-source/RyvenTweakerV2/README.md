# Ryven Tweaker V2
Native WPF .NET 8 Windows application. Three real per-user registry tweaks: Game Mode, Transparency, and Mouse Acceleration. Other two entries are explicitly manual-review only. This is a starter, not a 150-tweak optimizer. Undo restores exact original registry values only **during the same application session**; backups are not persistent. Do not close before undo if you need to restore original values. Mouse pointer changes may require signing out. Build with `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`. No performance gains guaranteed. The code has not been compiled or run in this environment; use GitHub Actions to verify.
